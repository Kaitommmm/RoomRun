# RoomRun — ระวังหมาดุ

เกมวิ่งหลบสิ่งกีดขวาง ควบคุมด้วยจอย XIAO ESP32C3 + MPU6050 สองอัน เชื่อมผ่าน Bluetooth LE พร้อมมอเตอร์สั่น รุ่นล่าสุด: 14 พฤศจิกายน 2026

## เลือก branch

| Branch | เนื้อหา | เหมาะกับ |
|---|---|---|
| [main](https://github.com/Kaitommmm/RoomRun/tree/main) | โปรเจกต์รวม: `web/` และ `controllers/` | เก็บหรือพัฒนาทั้งระบบ |
| [web](https://github.com/Kaitommmm/RoomRun/tree/web) | ซอร์สเว็บ เกม โมเดล เสียง เทสต์ และไฟล์ deploy | พัฒนาเกม / เชื่อม Netlify |
| [controllers](https://github.com/Kaitommmm/RoomRun/tree/controllers) | Arduino sketches ของจอยตัวแรกและตัวที่สอง พร้อม header ทุกไฟล์ | อัปโหลดเฟิร์มแวร์จอย |

ไฟล์ของแต่ละ branch เป็นชุดใช้งานได้แยกกัน ใน `main` อ่าน [คู่มือเว็บ](web/README.th.md) และ [คู่มือจอย](controllers/README.md)

## เว็บรุ่นนี้

- เลือกกระโดดด้วยการสะบัดสองจอยขึ้นพร้อมกัน หรือปุ่มเล็กขวา
- เลือกวิ่งแบบค่อย ๆ เร่งตามเวลา หรือแบบแรงแกว่งและจังหวะ
- ปุ่มเล็กซ้ายพักเกม ตอนพักใช้เล็กขวาวิ่งต่อ ใหญ่ขวาเริ่มใหม่ ใหญ่ซ้ายกลับเมนู
- วิธีเล่นปรับตามค่าที่เลือก มีปุ่มไปหน้าเกมบนแถบ Bluetooth และทดสอบเสียงในตั้งค่า
- เหรียญ คอมโบ ใกล้พลาด และอันดับในเบราว์เซอร์ ไม่มีไอเท็มพลังพิเศษ

## เปิดจาก main

ติดตั้ง Node.js 22.12+ หรือรุ่นที่ Vite 8 รองรับ แล้วรัน:

```bash
cd web
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดงด้วย Chrome/Edge การใช้ Bluetooth ต้องเป็น localhost หรือ HTTPS

## ทำเป็นลิงก์สาธารณะ

เชื่อม Netlify กับ repo นี้แล้วเลือก branch `web` ค่า build คือ `npm run build` และ publish directory คือ `dist` มี `netlify.toml` ให้แล้ว หากเลือก `main` ไฟล์ตั้งค่าระบุ base เป็น `web` ไว้ให้

อีกวิธีคือรัน `npm ci` และ `npm run build` ในโฟลเดอร์เว็บ แล้วนำโฟลเดอร์ `dist` ไปอัปโหลดผ่าน Netlify Drop หากโปรเจกต์เป็น Private ให้กด Make public ที่ Netlify

การอัปโหลด GitHub ครั้งนี้ยังไม่ได้ยืนยันการ deploy ใหม่บน Netlify หรือเว็บ ChatGPT เดิม อย่าใช้ลิงก์เว็บเดิมเป็นหลักฐานว่าเป็นรุ่นล่าสุด

## จอยและการทดสอบ

จอย First/Second คือโปรไฟล์ของบอร์ดจริงแต่ละตัว ไม่ได้ล็อกมือซ้าย/ขวา เลือก L/R ตอนเชื่อมในเกมได้ ค่าเทียบแบตต่างกัน ให้ใช้ไฟล์ตรงกับบอร์ดเดิม

เว็บรุ่นนี้ผ่าน 400 tests ใน 42 ไฟล์ โดยไม่นับ relay tests ที่ต้องเปิดพอร์ต และ production build ผ่าน ยังไม่ได้ทดสอบจอยจริงหรือคอมไพล์ Arduino ในรอบอัปโหลดนี้
