# RoomRun — ระวังหมาดุ

[English](README.md) | **ภาษาไทย**

เกมวิ่งบนเบราว์เซอร์ ควบคุมด้วยจอย RoomRun แบบ Bluetooth LE ที่ใช้ ESP32-C3 และ MPU6050 วิ่งอยู่กับที่เพื่อหนีหมาในซอย ความเร็วตัวละครอิงความถี่จังหวะที่จอยตรวจจับได้ เซ็นเซอร์ที่มือไม่ได้วัดการก้าวเท้า ท่านั่ง/ยืน หรือความเร็ววิ่งจริงโดยตรง

**[เปิดเกมเวอร์ชันล่าสุด](https://roomrun-bluetooth-play.kakar8882516.chatgpt.site/)** — ลิงก์ HTTPS สาธารณะเดียวสำหรับคอมและมือถือ เลือกมุมมองให้อัตโนมัติ ไม่ต้องล็อกอิน ChatGPT

## เล่นด้วยจอย Bluetooth

- **คอม Windows/macOS:** ใช้เบราว์เซอร์ที่รองรับ Web Bluetooth เช่น Chrome บน Windows ใช้ Edge ได้ด้วย คอมต้องมีอะแดปเตอร์ BLE ที่ใช้งานได้
- **Android:** เปิดผ่าน Chrome
- **iPhone/iPad:** เปิดลิงก์เกมใน [Bluefy](https://apps.apple.com/app/id1492822055) แล้วอนุญาต Bluetooth

เปิดจอย เลือกช่อง **L** หรือ **R** ในแผง Bluetooth กดเลือกจอย `RoomRun-…` แล้วเริ่มเกม หากจอยเชื่อมกับเครื่องอื่นอยู่ให้ตัดการเชื่อมต่อก่อน ไม่ต้องตั้ง Wi-Fi รหัสผ่าน หรือ IP ในจอย เกมนี้ใช้กับเฟิร์มแวร์ RoomRun BLE เดิมได้ การอัปเดตเกมไม่ต้องอัปโหลดโค้ดจอยใหม่

จอยเดียวใช้ทดสอบวิ่งและปุ่มเปลี่ยนเลนของข้างนั้นได้ การกระโดดด้วยการขยับต้องมีสองจอย ขณะทดสอบด้วยจอยเดียวบนคอมใช้ Space แทนได้

| การควบคุม | จอย RoomRun BLE | คีย์บอร์ด |
|---|---|---|
| วิ่ง | วิ่งอยู่กับที่ ความถี่จังหวะที่ตรวจจับได้กำหนดความเร็วเกม | A / D สลับกัน |
| เปลี่ยนเลน | ปุ่มหลักของ L ไปซ้าย ปุ่มหลักของ R ไปขวา | ลูกศรซ้าย / ขวา |
| กระโดด | ขยับทั้งสองจอยขึ้นพร้อมกันอย่างชัดเจน | Space |
| เริ่มใหม่ | ปุ่มเริ่มเกมใหม่ในแผงจอย | R |
| ทดสอบแรงสั่น | ปุ่มทดสอบของจอยที่เชื่อมอยู่ | — |

ปุ่มนักพัฒนา: **C** เรียกฝูงหมา และ **backquote (`)** เปิดแผงปรับค่าภายใน

## ตั้งค่าเกมและดูสถานะ

กด **ตั้งค่าเกม** ในแผง Bluetooth เกมจะหยุดชั่วคราวขณะเปิดเมนู แต่ยังรับข้อมูลจอยเพื่อทดสอบ ค่าเลือกจำไว้ในเบราว์เซอร์หากอนุญาตให้ใช้พื้นที่เก็บข้อมูล

- ค่าเริ่มต้นเป็นโหมด **ออกกำลังกาย · ทุกทิศทาง** ใช้แรงขยับทั้ง 3 แกน จับขึ้นลง ซ้ายขวา หน้า–หลัง และแนวเฉียง ต้องผ่านแรงขั้นต่ำและจังหวะต่อเนื่อง 3 ครั้งก่อนเริ่มวิ่ง กรองขาไปและขากลับไม่ให้นับซ้ำ ถือจอยตั้ง นอน หรือเอียงได้ แต่ยังต้องทดสอบกับฮาร์ดแวร์จริง
- **เล่นเบา / ทดสอบ · ทุกทิศทาง** ใช้สำหรับลองจอยและแกว่งแขนเล่น ส่วนโหมดขึ้นลงเดิมยังเลือกได้
- ความไวโหมดออกกำลังกายแยกจากโหมดเล่นเบา ปุ่มปรับอัตโนมัติใช้การวิ่งอยู่กับที่ 3 วินาทีและยังมีเกณฑ์แรงเด้งขั้นต่ำ
- ความเร็วเกมไล่ตามจังหวะที่ตรวจจับได้ มีการปรับให้ต่อเนื่องและยอมให้พลาดบางจังหวะ หน้าจอแสดงจำนวนจังหวะจอยต่อนาทีและความเร็วเกมเป็นเปอร์เซ็นต์ เป็นค่าประมาณสำหรับเกม
- ปรับเสียงเพลง เสียงเอฟเฟกต์ แรงสั่นในเกม และกราฟิกมาตรฐาน/ประหยัดได้
- แผงจอยแสดงสถานะเซ็นเซอร์ ข้อความวิเคราะห์ Bluetooth และข้อมูลแบตถ้าเฟิร์มแวร์รองรับ เปอร์เซ็นต์แบตเป็นค่าประมาณจากแรงดัน เกมยังไม่รายงานว่ากำลังชาร์จหรือชาร์จเต็ม
- ปุ่ม **เปิด / ทดสอบเสียง** ใช้เปิดและลองเสียง บน iPhone ให้ตรวจโหมดเงียบ ระดับเสียงสื่อ และเส้นทางเสียง/หูฟังด้วย มีไฟล์ MP3 สำรองสำหรับเบราว์เซอร์ที่อ่าน Ogg ไม่ได้

แรงสั่นในเกมเกิดตอนชน ถูกจับ และเริ่มฝูงหมาไล่ ต้องใช้เฟิร์มแวร์ BLE และวงจรมอเตอร์ที่รองรับ

## รันจากซอร์สโค้ด

ต้องมี Node.js ที่ Vite 8 รองรับ: 20.19+ หรือ 22.12+ ใช้ไฟล์ lock เพื่อติดตั้งเวอร์ชันตรงกัน

```bash
npm ci
npm run dev
```

เปิดลิงก์ที่ Vite แสดง ปกติคือ `http://localhost:5173/` การเชื่อม Bluetooth ผ่านเว็บต้องใช้เบราว์เซอร์ที่รองรับ บน localhost หรือ HTTPS

สำหรับเซิร์ฟเวอร์เกมในเครื่อง:

```bash
npm run build
node server/local.mjs
```

บน Windows เมื่อติดตั้งและ build แล้ว ดับเบิลคลิก `START_ROOMRUN.cmd` ได้ เปิดหน้าต่างนั้นค้างไว้ขณะเล่น เกมอยู่ที่ `http://localhost:8787/`

ไม่เก็บ `dist/` และ `node_modules/` ใน Git จึงต้อง build หลัง clone ใหม่ การเล่นจอย BLE บนเว็บ HTTPS ที่เผยแพร่แล้วไม่ต้องเปิดเซิร์ฟเวอร์ในคอม

### ใช้โทรศัพท์เป็นจอยผ่าน Wi-Fi (ทางเลือกเดิม)

```bash
npm run phone
```

คำสั่งนี้ build เกม เปิด relay ที่พอร์ต 8787 และ Cloudflare quick tunnel สแกน QR บนหน้าเกมด้วยโทรศัพท์แต่ละเครื่อง เลือกซ้าย/ขวาและอนุญาตเซ็นเซอร์ คอมเจ้าบ้านต้องเปิดค้างไว้และลิงก์ tunnel เปลี่ยนในแต่ละครั้ง หน้าเกม HTTPS ระยะไกลใช้ BLE โดยค่าเริ่มต้น หากตั้งใจใช้ relay/tunnel ที่รองรับให้เพิ่ม `?wifi=1` ปัจจุบัน relay มีห้องรวมเดียวและเก็บข้อมูลการขยับใน `logs/`

## กติกา

หมาวิ่งไล่ด้วยความเร็วคงที่ กระโดดข้ามหมานอน/โอ่ง และเปลี่ยนเลนหลบรถเข็น/ตุ๊กตุ๊ก ชนแล้วเสียระยะหรือเหรียญ ป้ายพื้นสีเหลืองเตือนกระโดด สีแดงเตือนเปลี่ยนเลน มีเหรียญและฝูงหมาไล่เป็นช่วง ๆ เกมจบเมื่อหมาตามทัน

## พัฒนาและทดสอบ

```bash
npm test
npm run build
```

ชุดทดสอบครอบคลุมการขยับ จังหวะวิ่ง เกณฑ์ออกกำลังกาย BLE แบต เสียงบนมือถือ การตั้งค่า แรงสั่น กติกาเกม และ WebSocket relay จริง ในสภาพแวดล้อมที่ไม่อนุญาตให้เปิดพอร์ต TCP ทดสอบส่วนอื่นได้ด้วย:

```bash
npm test -- --exclude tests/relay.test.js
```

โครงสร้างหลัก: `src/sim/` กติกา, `src/render/` ภาพ, `src/hud/` หน้าจอ, `src/input/` จอยและการตรวจจับ, `src/audio/` เสียง, `src/settings.js` ค่าที่จำในเบราว์เซอร์, `src/phone/` หน้าจอยโทรศัพท์, `server/` เซิร์ฟเวอร์, `art/` สคริปต์สร้างกราฟิก และ `scripts/replay.mjs` เล่นข้อมูลทดสอบซ้ำ
