# RoomRun Web — รุ่น 14 พฤศจิกายน 2026

เว็บเกมควบคุมด้วยจอย XIAO ESP32C3 + MPU6050 ผ่าน Bluetooth LE โค้ดจอยอยู่ branch [controllers](https://github.com/Kaitommmm/RoomRun/tree/controllers) หรือโฟลเดอร์ `main/controllers`

## การตั้งค่าที่เลือกได้

| การควบคุม | ตัวเลือก |
|---|---|
| กระโดด | สะบัดจอยทั้งสองขึ้นพร้อมกันสั้น ๆ หรือกดปุ่มเล็กขวา |
| วิ่ง | วิ่งต่อเนื่องแล้วเร่งจนเต็มประมาณ 6 วินาที หรือใช้แรงแกว่งและจังหวะ |

ปุ่มเล็กขวาที่หน้าเมนู/หน้าพักยังใช้เริ่มเกม/วิ่งต่อ ปุ่มเล็กซ้ายพัก ขณะพักใช้ใหญ่ซ้ายกลับเมนู ใหญ่ขวาเริ่มใหม่ การกลับเมนูจบรอบปัจจุบันและล้างระยะ เหรียญ คอมโบ แต่ยังเก็บการตั้งค่า อันดับที่บันทึกไว้ และการเชื่อมจอย

วิธีเล่นหน้าเมนูเปลี่ยนตามการตั้งค่า ปุ่มไปหน้าเกมย่อแผง Bluetooth และกลับไปจอเกม ทดสอบเสียงอยู่ในหัวข้อเสียงของตั้งค่า ไม่มีไอเท็มพลังพิเศษ เหรียญปกติ คอมโบ และอันดับในเบราว์เซอร์ยังอยู่

## เปิดเว็บจาก source

ต้องมี Node.js 22.12+ หรือรุ่นที่ Vite 8 รองรับ ถ้าใช้ branch main ให้ `cd web` ก่อน ถ้าใช้ branch web รันจากโฟลเดอร์ repo ได้เลย

```bash
npm ci
npm run dev
```

เปิด URL ที่ Vite แจ้งด้วย Chrome/Edge บนคอม หรือ Chrome บน Android ส่วน iPhone/iPad ใช้ Bluefy กับ HTTPS Bluetooth ต้องเปิดจาก localhost หรือ HTTPS

สร้างไฟล์เว็บ:

```bash
npm run build
```

ผลลัพธ์อยู่ `dist/` นำขึ้น Netlify Drop ได้ หรือเชื่อม Netlify กับ branch web ใช้ build `npm run build` และ publish `dist` มี `netlify.toml` ให้แล้ว หลัง deploy หากเป็น Private ต้องกด Make public

เปิด local server หลัง build: `node server/local.mjs` หรือ `START_ROOMRUN.cmd` แล้วเล่นที่ `http://localhost:8787/` หากใช้จอย BLE อย่างเดียว เว็บสาธารณะไม่ต้องมี local server หรือ relay ค้างไว้

## เชื่อมจอย

เปิดจอย เลือก L/R ในแผง RoomRun Bluetooth แล้วเลือกอุปกรณ์ให้ตรงตัว กดปุ่มเล็กขวาเพื่อเริ่ม หลังจอยหลุดเกมจะพักและพยายามเชื่อมใหม่ ต้องกดเล็กขวาเพื่อวิ่งต่อ ไม่มีการวิ่งต่อเองหลังเชื่อมกลับ

ตรวจจอย/บันทึกการเคลื่อนไหวได้จากตั้งค่า สำหรับท่าสะบัดต้องใช้จอยสองตัว ส่วนปุ่มกระโดดใช้ปุ่มเล็กขวาของจอยที่กำหนดเป็น R
