# RoomRun — ปรับหน้าเกมและตั้งค่า

รุ่น 14 พฤศจิกายน 2026: UI Update

- เพิ่มปุ่ม **ไปหน้าเกม** บนแถบ RoomRun Bluetooth ใช้ได้ทั้งตอนเปิดและย่อแผง ปุ่มจะย่อแผง ปิดหน้าตั้งค่า/หน้าบันทึกถ้าเปิดอยู่ และโฟกัสจอเกม โดยเก็บรอบปัจจุบันไว้ หากเกมพักอยู่ ใช้ปุ่มวิ่งต่อบนจอหรือปุ่มเล็กขวาตามเดิม
- ข้อความวิธีกระโดดด้วยปุ่มเปลี่ยนเป็น **ขณะเล่น: กดปุ่มเล็กขวา** เอารหัสขาและคำอธิบายต่อท้ายตามที่ขอออก
- แยกปุ่มเล็กซ้ายและปุ่มใหญ่ขวาในวิธีเล่นลงบรรทัดใหม่
- ย้าย **เปิด / ทดสอบเสียง** ไปที่หัวข้อ **เสียง** ในตั้งค่าเกม พร้อมข้อความแจ้งผล
- เปลี่ยนข้อความ **มือถือหลุด** เป็น **จอยหลุด**

การเลือกวิธีกระโดดสองแบบ การวิ่งสองแบบ ปุ่มพัก/กลับเมนู/เริ่มใหม่ และการจำค่าในเบราว์เซอร์คงเดิม ไม่ปรับการตรวจจับการเคลื่อนไหวหรือเฟิร์มแวร์

## เปิดเล่นในเครื่อง

1. ปิดเซิร์ฟเวอร์ RoomRun ตัวเก่า
2. ดาวน์โหลด ZIP ใหม่และแตกลงโฟลเดอร์ใหม่
3. เปิด `START_ROOMRUN.cmd` ต้องมี Node.js 22 หรือใหม่กว่า
4. เปิด `http://localhost:8791/` ผ่าน Chrome/Edge แล้วเชื่อมจอย

เซิร์ฟเวอร์ขึ้น `RoomRun UI Update 2026-11-14` และชื่อแท็บลงท้าย `UI Update 14 Nov` ไม่ต้องอัปโหลดโค้ดจอยใหม่
